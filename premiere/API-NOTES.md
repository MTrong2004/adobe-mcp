# Premiere UXP API provenance

Reviewed official sources 2026-11-17. Target installed Premiere 26.0.1 (lead verified executable 26.0.1.3); manifest minimum 26.0.0. No CEP/ExtendScript bridge.

- [Reference overview](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/): `require('premierepro')`, async methods/synchronous properties.
- [Project](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/project/): getActiveProject, getRootItem, getSequences, importFiles(paths,true,target,false), createSequenceFromMedia(name,ClipProjectItem[],target), saveAs(path), lockedAccess(callback), executeTransaction(callback,label) since25.6. Transactions are synchronous callbacks; never async inside lock. Async direct mutation methods are called outside transaction.
- [ProjectItem](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/projectitem/): getId() since25.6. Legacy contract name item_node_ids means strings from this actual method, not CEP nodeId.
- [FolderItem](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/folderitem/): cast/getItems/createBinAction(name,makeUnique) since25.6; avoid FolderItem.type property tagged27.
- [ClipProjectItem](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/clipprojectitem/): cast/isSequence/getMediaFilePath/getComponentChain since25.6; avoid createSubClipAction26.3 and properties tagged27.
- [Sequence](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/sequence/): guid/name/get*Track/get*TrackCount/getEndTime since25.6.
- [SequenceEditor](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/sequenceeditor/): getEditor and createInsertProjectItemAction(ProjectItem,TickTime,videoIndex,audioIndex,limitShift) since25.6. Both indices required. No documented negative sentinel is assumed. Mixed AV requires optional companion_track_index authorized by lead and accepted by shared core. Existing tracks only; verify both streams. Media streams detected with documented getComponentChain(MediaType).
- [VideoClipTrackItem](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/videocliptrackitem/): getProjectItem/getStartTime; readback counts matching item+start on destination tracks before/after. 0.05sec tolerance accommodates timeline frame snapping, not frame accurate editorial validation.
- [EncoderManager](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/encodermanager/): getManager/exportSequence(sequence,Constants.ExportType.IMMEDIATELY,output,preset,true) since25.6. Never launchEncoder/startBatchEncode (26.3). Nonempty new output required after awaited API return; otherwise outcome_unknown, never fake completed/AME queue success.
- [Raw official sequence sample](https://raw.githubusercontent.com/AdobeDocs/uxp-premiere-pro-samples/main/sample-panels/premiere-api/src/sequence.ts), [sequence editor sample](https://raw.githubusercontent.com/AdobeDocs/uxp-premiere-pro-samples/main/sample-panels/premiere-api/src/sequenceEditor.ts), [project panel sample](https://raw.githubusercontent.com/AdobeDocs/uxp-premiere-pro-samples/main/sample-panels/premiere-api/src/projectPanel.ts): checked signatures and synchronous lockedAccess/executeTransaction usage.
- [Raw official manifest](https://raw.githubusercontent.com/AdobeDocs/uxp-premiere-pro-samples/main/sample-panels/premiere-api/public/manifest.json): host.app premierepro, manifestVersion5.
- [Official raw declarations](https://raw.githubusercontent.com/adobe/premierepro-types/main/src/premierepro.d.ts): checked ProjectItem.getId, SequenceEditor parameters, synchronous track.getTrackItems returns array, TickTime.createWithSeconds. Current declarations27 include newer APIs; reference minimum-version tags take precedence.

- [Official shared UXP FSAPI](https://developer.adobe.com/photoshop/uxp/2022/uxp-api/reference-js/modules/fs/fs): require('fs').lstat(path) returns a Promise; require('fs').promises.stat is not assumed. Native paths default file: scheme. isFile/size used for disk verification, ENOENT normalized, other failures propagated.
- [Official shared UXP host information](https://developer.adobe.com/photoshop/uxp/2022/uxp-api/reference-js/modules/uxp/host-information/host): require('uxp').host.version string. Dispatcher rejects missing/malformed/older-than26 version.

Node mocks test contract behavior against these documented shapes. They do not establish live host compatibility, successful export, or installation. No live UXP operation has been verified in this implementation session.
